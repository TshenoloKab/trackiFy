# Trackify
Trackify is a habit tracker that helps users stay consistent with their daily goals by tracking habits and visualizing progress. Built with React and CSS, it offers a simple, clean, and responsive experience across devices.

## 🧠 What It Solves
It helps users build lasting routines by offering an interface for logging daily habits and tracking personal progress over time.


## ✨ Features
- Add and remove custom habits
- Check off completed tasks per day
- Reset for a new day
- Progress bar showing % completion
- Clean, mobile-friendly UI
- Persistent data (localStorage)


## 🔧 Tech Stack
- React 
- CSS
- LocalStorage
